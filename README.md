# Révisions M1 — Bases de données avancées

Site interactif de révision sur JSON Schema, XML, XSD et les espaces de noms.

## Contenu

- fiches synthétiques JSON Schema et XML/XSD ;
- pièges fréquents ;
- quiz avec score et explications ;
- flashcards cliquables ;
- fonctionnement hors ligne, sans dépendance.

Ouvrir `index.html` dans un navigateur.
